# Investigation Dossier

COMP 8117 Investigation Dossier. Theme: Software Engineer or Software Management, similarities and differences.

Team Abhinav Pandey, Shrijana Karki, Aakriti Mainali, Khemraj Adhikari and Nishan Giri.

## papers

- `candidates_to_review.csv` 79 papers that passed a mechanical screen (abstract, venue, mentions software and a management or leadership role), with a reviewer assigned to each. Fill in keep_yes_no and why.
- `assignments.md` the same split as a readable list per member.
- `papers_v2.csv` all 137 results including those that failed the screen and the reason.
- `search_log_v2.csv` every query, filter and hit count for the methodology section.
- `pdfs/` open access PDFs. Paywalled papers are reached through Leddy Library using the DOI.
- `fetch_papers_v2.py` the search script. Replace the queries with the team's own search strings and rerun.
- `first-search/` the earlier single round search.

Target after review is about 15 papers before 2020, about 10 from 2020 onward and about 5 on LLMs and AI agents. The search was run on OpenAlex. Run the same strings in IEEE Xplore and ACM through Leddy as well.
