# Test data

Stanford CS231n Lecture 2, a public lecture with 98 slides. The PDF itself is not committed. Run `./fetch.sh` to download it.

- `original-pdf-inspection.txt` shows the file has no tags, no structure tree, and that slide 23 is mostly two pictures
- `slide-22-text.txt`, `slide-23-text.txt`, `slide-52-text.txt` are all the text a screen reader can get from those slides
- `silent-slides.html` compares what a sighted student sees with what a screen reader gets
