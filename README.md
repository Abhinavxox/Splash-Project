# Accessible lecture slides

COMP 8117 SPLASH project. Team Abhinav Pandey (lead), Shrijana Karki, Aakriti Mainali and Khemraj Adhikari.

Lecture slides store pictures and text boxes but not what they mean, so a screen reader cannot tell a blind student what a formula, table or diagram says. This project investigates how much of that meaning can be added back automatically and accurately.

## Layout

- `ideas/` earlier project ideas and plans, including the GPU scaling plan we moved away from
- `research/` papers, tools and notes from our investigation
- `test-data/` the public lecture we tested on and what a screen reader can get from it
- `prototype/` first pipeline that rebuilds slides as accessible HTML
- `docs/` progress reports, proposal and the decisions log
