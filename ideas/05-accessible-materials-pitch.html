COMP-8117 · SPLASH proposal · draft

Course materials every student can read

Turning lecture slides into files that blind and low-vision students can use with screen readers and braille displays, on the same day as everyone else.

The problem

Blind and low-vision students read course materials with screen readers (speech) and braille displays. Both only work if a file is properly structured. Most lecture PDFs and slides are not: the reading order is scrambled, diagrams are read as just “image”, math comes out as gibberish, and tables become a jumble of numbers.

The fix today is the accessibility office converting files by hand, which takes days. Sighted classmates have the material instantly.

Blind students fall behind, not because of ability, but because of file formats.

What exists, and why it isn't enough

Today's approachWhere it fails
Adobe's accessibility checkerFinds problems, doesn't fix diagrams or math
Auto-tagging toolsWork on plain text, break on slides, math and tables
Staff converting by handAccurate but slow, can't keep up
Asking instructors to fix itMost don't know how or don't have time

Each tool solves one piece. Nobody has fixed the journey from the instructor's file to a student who can read it on time.

Our approach: investigate, then build

  1. Investigate (weeks 6–7). Interview the accessibility office, blind and low-vision students and instructors. Run real course files through today's tools and record where they break. Measure how long students wait.
  2. Decide (week 7). The evidence chooses the fix. Working focus: math- and diagram-heavy lecture slides, turned into accessible HTML that works with screen readers and braille displays.
  3. Build and test (weeks 8–10). Fix reading order and structure, add AI-written diagram descriptions, convert math to MathML, and flag anything uncertain for a human to check.
  4. Prove it (weeks 9–10). Real files, real students, before and after.

We don't build braille output. Existing tools (Liblouis, MathCAT) handle that once content is structured correctly. This is a deliberate, recorded decision.
